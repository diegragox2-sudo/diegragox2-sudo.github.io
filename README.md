# Barbería Donde El Canche

Sitio web de la barbería: inicio, productos con carrito (pedido por WhatsApp) y agendado de citas por WhatsApp. Adaptado para celular y computadora.

## Archivos

- `index.html` – página de inicio
- `productos.html` – catálogo y carrito
- `citas.html` – formulario de citas

## Ver el sitio

Publicado con GitHub Pages (Settings → Pages → Deploy from a branch → main / root).
